# Suzukuri 0.2.0

## Summary

0.2.0 adds repository-mapped bounded execution (`test`, `verify`, `diff`),
deterministic reuse of semantic execution results for identical repository
content, and a canonical command contract with progressive `--help`,
`--diagnose`/`--doctor`, and a `suzukuri skill` playbook surface.

## Added

- `suzukuri test`: repository-mapped semantic test execution over a bounded,
  fixed-capacity streaming process runner, with Node TAP support through the
  existing test-result projection.
- `suzukuri verify`: repository-mapped semantic verify execution over the
  same bounded execution primitive, preserving exit/signal outcomes and
  bounded stage-aware failure semantics.
- `suzukuri diff`: bounded semantic diff acquisition over the existing Git
  diff adapter and views, covering working-tree, staged, and all-diff modes.
- Deterministic repository-content fingerprinting
  (`src/repository-fingerprint.ts`) and a bounded on-disk execution-result
  cache (`src/execution-cache.ts`) so `suzukuri test` and `suzukuri verify`
  reuse a prior semantic result when repository content is unchanged.
- A versioned canonical command contract (`src/command-contract.ts`) shared
  by execution dispatch and help resolution, so every command is documented.
- Progressive `--help` at root, domain, and leaf command depth, plus
  `--help=full`, `--help=json`, and a namespaced `--version` string.
- `--diagnose` / `--doctor`.
- `suzukuri skill`, exposing AGENTS.md's bounded operational playbooks.
- `.suzukuri/commands.json` wiring this repository's own test execution
  through the suzukuri CLI.

## Changed

- The minimum supported Node.js version is now Node.js 24 (previously
  `>=22.13`).
- README restructured to match Wabachi's layout (hero image, badge row);
  detailed usage moved to `docs/USAGE.md`.

## Fixed

- Required semantic subtrees are now protected during generic budget
  reduction, instead of being eligible for reduction like unrelated
  siblings.
- `yohn-jp/.github` reusable workflow references are now recognized as
  `@main`-pinned by policy, instead of being flagged as unpinned.

## Breaking changes / migration

Node.js 22 is no longer supported. Upgrade to Node.js 24 or newer before
installing Suzukuri 0.2.0.

## Upgrade

```bash
npm install --global suzukuri@0.2.0
suzukuri --version
suzukuri --help
suzukuri skill
```

Expected version output:

```text
0.2.0
```
