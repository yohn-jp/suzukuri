# Suzukuri 0.3.1

## Summary

0.3.1 is a maintenance patch with no user-facing runtime or API changes. It
removes the init-command lockfile tests' dependency on fetching the candidate
Suzukuri version from npm before that version has been published.

## Added

No user-facing features were added.

## Changed

- Init-command tests use a local package fixture for the package-manager
  lockfile-update boundary, keeping prepublication verification independent
  of npm registry availability.

## Fixed

- Release verification no longer fails because init-command tests try to
  resolve the not-yet-published candidate version from the public npm registry.

## Breaking changes / migration

None. Suzukuri's runtime behavior and public APIs are unchanged.

## Upgrade

```bash
npm install --global suzukuri@0.3.1
suzukuri --version
```

Expected version output:

```text
suzukuri 0.3.1
```

## Release verification

Before merge, run `pnpm run verify`. The tag-triggered `v0.3.1` publishing
workflow rebuilds and tests the package, packs one tarball, certifies that the
release tag, checked-out source SHA, and tarball SHA-256 match, then smoke-tests
and publishes those exact bytes through npm Trusted Publishing.
